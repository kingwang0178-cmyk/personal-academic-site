TECHNICAL / ENGINEERING EVIDENCE

02

TECHNICAL PROJECT / DESKTOP SYSTEM

Prompt Optimizer

A Tauri 2 desktop tool that turns an underspecified prompt into a more executable prompt while attempting to preserve the user's original action and avoid invented constraints. The system combines a React/TypeScript interface, Rust backend, DeepSeek integration, deterministic checks, and regression-oriented evaluation.

ProblemReduce ambiguity and instability when users give short or underspecified instructions to LLMs.
ApproachDepth and requirement analysis, local guards, scenario-aware prompt construction, structured model output, and post-generation checks.
OutputWorking desktop application plus a 41-case quality benchmark and regression-oriented evaluation materials.
RoleIndependent project development, system design, implementation, and evaluation.
ReactTypeScriptTauri 2RustDeepSeek

Positioning: engineering / independent project evidence; not presented as biomedical research.

Scientific Figure & Research Communication Workflow

An ongoing effort to build a more rigorous workflow for generating publication-oriented scientific figures, including architecture and process diagrams. The work treats figure generation as an engineering and communication problem rather than decorative illustration.

OutputReusable figure-generation workflow, validation scripts, style guidance, and iterative architecture-figure prototypes.
